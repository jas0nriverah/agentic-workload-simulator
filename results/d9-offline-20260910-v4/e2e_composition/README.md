# Conditional E2E composition audit

Use `audit.py` to check interval topology and request joins on the 43 fully
valid CPU cases / 22 instances. Use `fit.py` for the subsequent bounded
conditional-replay model comparison. Both read retained evidence only.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 docs/d9-salvage-20260910/e2e_composition/audit.py
PYTHONDONTWRITEBYTECODE=1 python3 docs/d9-salvage-20260910/e2e_composition/fit.py
uv run --no-sync python -m pytest -q docs/d9-salvage-20260910/e2e_composition/test_audit.py docs/d9-salvage-20260910/e2e_composition/test_fit.py
```

Read [REPORT.md](REPORT.md) for the exact reconstruction, identity proof, model
contract, and held-out results. `audit.json`, `fit_report.json`,
`fit_artifact.json`, and `fit_predictions.jsonl` are regenerated by the commands
above.

Raw-free prediction from a supplied conditional replay trace is available as:

```sh
python3 docs/d9-salvage-20260910/e2e_composition/predict.py \
  docs/d9-salvage-20260910/e2e_composition/example_request.json
```
