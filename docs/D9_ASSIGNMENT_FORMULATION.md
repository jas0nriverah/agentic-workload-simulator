# Assignment formulation

The current authority mapping is [PDF_CONTRACT.md](current/PDF_CONTRACT.md),
based on both pages and figure examples of the original PDF.

The Step 3 → Step 4 structure supports conditional simulation using supplied
CPU/GPU workload descriptors and hardware parameters. This is an interpretation;
the PDF does not specify the evaluator input schema or explicitly settle event
granularity. Keep these uncertainties visible.

Target-machine latencies and measured residuals are labels, never predictors.
A supplied token workload does not imply that target-machine realized cache
state is a hardware-independent input. The older prospective forecasting
experiments are separate evidence, not a replacement for this assignment contract.
